🛩️ DJI Mavic 4 Pro — Product Landing Page

A modern, product-focused landing page showcasing the DJI Mavic 4 Pro drone. The website features a hero section with product details and pricing, a specifications comparison table, customer ratings and reviews, related accessories, and a multi-section footer.

✨ Features

🚁 Product hero section with pricing, availability, and call-to-action buttons.

📊 Product specifications comparison table.

⭐ Customer ratings, review statistics, and testimonials.

🛍️ Related products and accessories showcase.

❤️ Add to Cart and Wishlist interface elements.

🧭 Navigation bar with smooth section-based navigation.

📱 Structured layout designed for a product-focused shopping experience.

🔗 Footer with product categories, support links, company information, and social media links.

🛠️ Technologies Used

HTML5

CSS3

JavaScript (for future interactivity)

Responsive web design principles

🎯 Project Goals

This project demonstrates my front-end development skills in building structured landing pages, organizing complex product information, creating comparison tables, and designing reusable visual sections with a focus on user experience and product presentation.
